# 아덴의 밤 - 고해상도 캐릭터 아트 / 웹 배포 패키지

## 로컬 실행 (Windows)
1. Node.js 18 이상 설치
2. 이 폴더에서 CMD 실행
3. `npm.cmd start` 입력
4. 브라우저에서 http://localhost:8080 접속

PowerShell에서 npm.ps1 정책 오류가 발생하면 `npm.cmd start`를 사용하세요.

## 다른 사람에게 공개 (GitHub Pages)
이 패키지의 `index.html`과 `assets` 폴더를 GitHub 저장소 최상위에 업로드합니다.
- GitHub 저장소 > Settings > Pages
- Build and deployment에서 Deploy from a branch 선택
- Branch: main, Folder: /(root) 선택 후 Save
- Pages가 표시하는 주소를 다른 사람에게 공유합니다.

GitHub Pages는 정적 웹사이트 호스팅입니다. 이 게임은 현재 브라우저에서 플레이하는 형태이며, 계정/공용 저장/실시간 멀티플레이 서버는 포함하지 않습니다.
